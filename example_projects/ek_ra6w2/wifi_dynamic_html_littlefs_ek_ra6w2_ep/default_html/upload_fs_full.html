507 - Insufficient Storage

The upload cannot be completed because the filesystem has insufficient free space.

Error Details:
The filesystem must maintain at least 5% free space for system operations. Your upload would exceed this limit.

💡 What you can do:

  • Delete unnecessary files from the filesystem
  • Try uploading a smaller file
  • Check available disk space before uploading
  • Contact the system administrator if you need more storage
